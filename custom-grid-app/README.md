## 🔧 Stack

- Angular 19 with Standalone Components
- SCSS (no external CSS frameworks)
- API Integration: https://01.fy25ey01.64mb.io/
- Charts: ApexCharts (ng-apexcharts)

## 💻 Features

- Responsive-like layout for 1920x1080
- Sidebar + Topbar layout
- Data grid (custom HTML/CSS) with:
  - Add / Edit / Delete rows
  - Confirmation modal for delete
- Loading indicator while fetching data
- Weekly performance chart using ApexCharts

✅ Notes
Data operations (add/edit/delete) are local only.

All components are built from scratch with custom SCSS.

Angular best practices applied: modular, reusable, clean code.
